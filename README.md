# 阅读器 (eReader)

一个 Windows 桌面电子阅读器，原生支持 EPUB / MOBI / AZW3 / FB2 / PDF / TXT，特性包括：

- **超大字体**：滑条 12–200 px，数字输入无上限，Ctrl+滚轮 实时调整
- **多种翻页方式**
  - 键盘：空格 / ← / → / PgUp / PgDn / J / K（可自定义）
  - 鼠标点击：左 1/3 上一页，右 2/3 下一页
  - 鼠标滚轮：向下滚翻下页
  - 自动翻页：F9 启停，间隔 5–120 秒可调
  - 自定义按键：可为任一动作绑定多个键 / 组合键
- **基础功能**
  - 自动保存阅读进度（按文件指纹存储，与文件移动解耦）
  - 7 套背景主题：白底 / 米黄 / 护眼绿 / 深灰 / 夜间 / 纯黑 / 自定义
  - 行间距、页边距、字体族独立可调
  - 拖放打开、最近阅读列表、目录跳转
  - PDF 三种模式：连续滚动 / 单页 / 重排文本（适配大字体）

## 开发

```bash
npm install
npm run dev      # 启动 Electron + Vite HMR
```

## 预览生产构建

```bash
npm run build    # 仅构建
npm start        # 用 Electron 启动构建好的产物
```

## 打包成 .exe（NSIS 安装包）

```bash
npm run package
```

首次执行会下载 Electron 运行时（约 150 MB），耐心等待。
输出位于 `release/` 目录，例如 `release/阅读器-0.1.0-x64.exe`。

## 自定义图标

将一张 256×256（或更大）的 PNG 放到 `build/icon.png` 即可被 electron-builder 自动采用。
Windows ICO 文件可放 `build/icon.ico`。

## 技术栈

- Electron + electron-vite + TypeScript
- React 18 + Tailwind CSS + Zustand
- foliate-js (EPUB / MOBI / AZW3 / FB2)
- pdfjs-dist (PDF)
- electron-store (设置 + 进度持久化)

## 默认快捷键

| 动作 | 快捷键 |
|---|---|
| 下一页 | 空格 / → / PgDn / J |
| 上一页 | ← / PgUp / K |
| 自动翻页 | F9 |
| 打开文件 | Ctrl+O |
| 设置 | F10 |
| 目录 | F4 |
| 全屏（隐藏工具栏） | F11 / F8；Esc 退出 |
| 字号 +2 | Ctrl+= |
| 字号 −2 | Ctrl+− |
| 字号实时调 | Ctrl+滚轮 |

均可在 设置 → 按键 中自定义。

## 全屏阅读

“全屏”同时进入系统全屏并隐藏工具栏；点击浮动的“退出全屏”，或按 Esc、F11、F8 返回普通阅读界面。全屏时鼠标静止 3 秒自动隐藏，移动立即显示，电子书内页同样生效。原有沉浸快捷键和点击设置会合并为全屏操作。

## 语音控制（Windows）

打开书籍后，点击工具栏的麦克风按钮开启语音控制。绿点表示正在监听，黄点表示启动中；悬停可查看状态和口令：

- “下一页”或“下翻”：下一页。
- “上一页”或“上翻”：上一页。
- “放大”或“字大一号”：字号增加 2；PDF 则放大页面。
- “缩小”或“字小一号”：字号减少 2；PDF 则缩小页面。
- “开始自动翻页”“停止自动翻页”：开启或停止自动翻页。
- “进入全屏”“全屏模式”“打开全屏”“全屏”：进入全屏阅读。
- “退出全屏”“普通模式”“关闭全屏”“退全”：退出全屏阅读。“退全”不会关闭阅读器；单说“退出”不作为口令。
- “关闭语音控制”：停止监听。

设置 → 语音控制中，“成功执行时播放音效”“显示语音识别情况”默认均开启，修改后会保存。成功执行后播放短提示音，未识别或操作失败时不响。识别情况使用小浮层显示监听、识别和执行结果，不增加工具栏行数；可随时关闭显示。

“仅语音翻页”默认关闭，开关状态随设置保存。开启后立即只允许“上一页 / 上翻 / 下一页 / 下翻”，其他语音口令均忽略且不播放成功音效；点击麦克风按钮仍可关闭监听。关闭此开关恢复全部口令。此模式保留完整识别词表和普通语句过滤，只限制允许执行的动作，不会把其他口令改作翻页。已经开始执行的操作不会撤销；键盘、鼠标和已开启的自动翻页不受此开关影响。

使用 Windows 本机简体中文语音识别，无需云端账号，不上传录音。需要安装 Windows 简体中文语音识别组件，并允许桌面应用访问默认麦克风；缺少组件或麦克风不可用时，界面会提示。安装组件后可重新点击开关。

语音控制默认关闭；再次点击麦克风、切换书籍、返回首页、刷新或退出阅读器会停止监听。全屏时保留浮动麦克风和退出按钮。语音控制与现有朗读功能互斥，本次不加入朗读口令。

普通语句与口令一起参与识别，避免把所有声音强行匹配成口令；只有完整匹配且达到置信度要求的结果才会执行，两个字的短口令要求更高。对不确定的短语再用独立翻页词表检查，复核只能翻页，不能改变字号或全屏状态。复核音频仅临时留在内存中，随后释放。短时间重复结果不会执行。请清楚、单独说出口令；这能减少误触，但相近发音、口音、距离和环境噪声仍可能影响识别，不能保证完全杜绝误识别。

## 数据存储位置

所有设置和阅读进度位于：

```
%APPDATA%\阅读器\ereader.json
```

删除此文件即可重置所有设置。
