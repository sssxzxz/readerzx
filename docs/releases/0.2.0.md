# 阅读器 0.2.0

新增个人声音朗读、生成前试听、整本书后台生成及音色库。生成好的部分可以立即点读；未完成的位置优先生成，任务可暂停、重试并在重启后继续。

- 保存多个音色，同一本书可保留不同音色的音频。
- 支持暂停、继续、播放端变速和本地缓存播放。
- 修复窗口最小化后的句间停顿，并保护书籍内容和音色版本之间的缓存隔离。
- 保留原有翻页、语音控制与阅读设置。

## 效果与限制

用户评价：**“音色尚可，但是太慢了。”** 当前个人声音功能仍需改进生成速度。

- 测试电脑上，已生成内容的点读输出响应约 0.10 秒；新内容约需 47 秒生成一分钟音频。Windows 康康同文测试约需 0.23 秒，当前方案尚未达到其合成速度。
- 30 分钟、995 个片段的静音连续播放检查通过，验证了顺序与衔接，不代表 30 分钟的人工听感验收。
- TXT、EPUB、FB2 和含文字 PDF 已验证；MOBI、AZW3 的个人声音功能尚未完成实际验证，扫描 PDF 暂不支持 OCR。

## 安装与环境

安装包适用于 Windows x64，未签名。**安装包不包含个人录音、生成音频、书籍、声音模型、Python 或 FFmpeg。** 普通阅读和 Windows 系统朗读可独立使用。

个人声音功能需要额外配置本地 ZipVoice-Distill INT8 / sherpa-onnx 环境，并导入自己的录音与对应文字。已有本机配置及音频保存在用户资料目录，升级后继续使用；其他电脑请按 [使用说明](https://github.com/sssxzxz/readerzx/blob/main/docs/personal-voice.md) 配置。

本次不增加 MP3/MP4 转换功能；预生成音频仍使用 WAV。代码、报告与安装包发布不包含个人声音资料。
