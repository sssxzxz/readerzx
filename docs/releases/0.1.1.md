# 阅读器 0.1.1

- 新增 Windows 本地中文语音控制，支持翻页、字号、自动翻页及全屏口令。
- 新增“仅语音翻页”开关，默认关闭，开启后只执行“上一页／上翻／下一页／下翻”。设置自动保存。
- 增加普通语句过滤和短口令校验，保留“放大／缩小”“字大一号／字小一号”。
- 全屏支持“进入全屏／全屏模式／打开全屏／全屏”及“退出全屏／普通模式／关闭全屏／退全”。
- 合并沉浸与全屏，鼠标静止 3 秒后自动隐藏；优化语音控制布局，增加默认开启的成功音效和识别反馈开关。
- 修复 PDF 类型检查、加载超时重试及电子书加载期间切换全屏的异常。

安装包适用于 Windows x64，未进行代码签名。语音控制需要 Windows 简体中文语音组件及麦克风权限；识别效果受口音、距离和环境声音影响。

验证：类型检查、生产构建、语音控制协议测试、合成语音及噪声测试、阅读器界面回归检查通过。合成语音测试不代表真人麦克风识别准确率。
