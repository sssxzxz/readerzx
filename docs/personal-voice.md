# 用自己的声音听书

个人声音功能使用轻量直接克隆，在本机 CPU 上生成语音。本次开发用户的评价是「音色尚可，但是太慢了」。安装包不包含用户的音色；其他使用者需要配置环境并导入自己的录音。

## 安装与声音环境

从仓库 Releases 下载 Windows x64 安装包后启动阅读器。普通阅读和 Windows 系统朗读不需要声音模型；个人声音合成另外需要下列本地文件。

- Python：本次验证使用 Python 3.11，填写 `python.exe` 的完整路径。
- 运行库：本次验证使用 `sherpa-onnx 2.0.1`、匹配的 `sherpa-onnx-core` 与 NumPy；填写包含这些包的目录。
- 音频转换：填写本地 `ffmpeg.exe` 的完整路径。
- 模型：按 [sherpa-onnx 官方 ZipVoice 文档](https://k2-fsa.github.io/sherpa/onnx/tts/zipvoice.html) 准备 INT8 模型和声码器，目录结构如下。

```text
模型目录/
  vocos_24khz.onnx
  lexicon-en-us.txt                 # 可选英文词典
  sherpa-onnx-zipvoice-distill-int8-zh-en-emilia/
    encoder.int8.onnx
    decoder.int8.onnx
    tokens.txt
    lexicon.txt
```

在「声音与听书 → 本地环境设置」填写四个路径并保存。已有 Aixora 环境时，可复用其 Python 与 FFmpeg。当前没有自动下载及修复向导；首次准备环境后，请先用一段短文字试听。

## 日常使用

1. 启动已安装的阅读器；从源码运行时先执行 `npm run build`，再执行 `npm start`。如果阅读器已打开旧版本，请关闭后重新打开。
2. 打开书籍，点击工具栏的「声音与听书」，选择已经导入的音色。首页也有这个入口，可以设置默认声音。
3. 用「生成前试听」填写一小段文字，点击「生成试听」，生成后按播放器的播放按钮试听。
4. 点击「生成整本书」。音频按句保存，已经完成的部分立即可用，无须等全书完成。
5. 开启「点读模式」，点击正文里的文字，从该句连续朗读。点到尚未完成的句子会优先生成，完成后自动播放；正在生成的上一句可能先完成。

F6 或工具栏「朗读」可以开始、暂停和继续；「停止」结束本次播放。播放速度支持 0.5～2 倍，并保留音高。改变播放速度不会重新合成音频。

关闭点读模式会恢复原来的正文点击翻页。选中文字、点击链接或笔记不会启动点读。

## 生成进度与恢复

- 「暂停生成」允许当前句子完成后暂停，保留所有已完成音频。
- 关闭阅读器后，任务和音频仍会保留。下次打开后点击「继续生成」，避免启动时自动占用 CPU。
- 已完成音频可以离线播放，即使声音生成程序暂时不可用。
- 失败的句子可以单独重试；检测到缺失或损坏的音频时，可以继续生成修复。
- 「清理音频」只清理所选任务和该任务的音频，保留原书和音色。
- 修改书籍内容或更换声音模型会创建不同音频版本。旧版本保留；内容不一致的旧音频不会对着当前书籍播放。

## 保存更多声音

展开「保存新的音色」，填写名称、录音对应的完整文字，再选择录音文件。建议使用 5～20 秒的单人清晰录音；支持范围为 2～60 秒。原录音保持不变，应用另存一份供克隆使用。

每个声音都可以独立命名、试听，并为不同书籍选择。删除音色会停止相关生成并清理应用保存的录音副本；原录音不变，已经生成的书籍音频仍然保留。

这里保存的是供本地克隆模型复用的声音资料，不是训练后的独立小模型，也不是安装到 Windows 系统里的 TTS 语音。

## 速度与当前范围

已生成音频的点读响应，实测约 0.10～0.13 秒。测量范围为软件点击请求到电脑音频输出出现信号，使用 10 毫秒采样块；不是实体鼠标到空气声音的测量。

已通过 30 分钟、995 个片段的连续播放检查，包含窗口最小化的情况；最大额外衔接间隔约 49 毫秒。该检查使用静音输出核对顺序及衔接，详细范围见同目录的 `personal-voice-validation.md`。

2026-11-16 在这台电脑上，通过阅读器的实际逐句生成流程，把同一段测试文字生成了 57.56 秒音频，用时 45.03 秒，折合每分钟音频约需 46.94 秒生成，包含声音引擎冷启动。首句生成完成约需 6.54 秒；这和已经生成内容的点读响应是不同的指标。句子长短、文字和电脑负载都会影响速度。

同一天用完全相同的文字测试 Windows 康康，三次生成速度的中位数约为每分钟音频 0.23 秒。个人音色的新内容合成仍明显慢于 Windows TTS，因此推荐预生成。可在面板观察已完成句数、音频时长、占用空间和预计剩余时间；估算会随实际生成进度更新。

TXT、EPUB、FB2 和含文字的 PDF 已做过实际生成与点读验证，包括 EPUB、FB2 跨章节连续朗读。扫描图片 PDF 需要先转换成文字；不能提取的页或章节会显示提示。MOBI、AZW3 使用共同的电子书提取路径，但本次未完成这两种格式的个人声音端到端测试。

音频目前保存为单声道 WAV，24 kHz、16 位，大约每小时 165 MiB。可以在任务面板按需清理。

## 数据与环境文件

- 声音和任务：`%APPDATA%\ereader\narration`
- 模型与运行库：按本地环境设置中的路径保存；源码开发时也可放在项目的 `.local` 目录。
- 如果复用了 Aixora 的程序，移动或删除其目录后需要重新配置路径。

0.2.0 安装包只分发阅读器，不捆绑上述声音环境及个人资料。代码和安装包的发布状态以仓库 Releases 为准。
